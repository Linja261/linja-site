Wichtig zum Schutz

Gate und Guard sind Client-Schutz auf GitHub Pages. Das Repo Linja261/linja-site ist öffentlich, das Passwort steht im Klartext in office.js, und das Gate versteckt den Inhalt nur per CSS — ausgeliefert wird er trotzdem. Wer die URL kennt und in den Quelltext schaut, liest alles.

Das hält Zufallsbesucher und Suchmaschinen ab. Es ersetzt keinen Login. Nichts hier ablegen, dessen Offenlegung wirklich schadet — keine Firmeninterna, keine Vertragsdetails, keine Kundendaten, keine Namen mit Bewertung.

Schutz-Arten

Gate

Passwortwand auf der Seite selbst. Der Inhalt bleibt unsichtbar, bis office.js freischaltet.

Guard

Leitet ohne Login zur Passwortabfrage um und danach zurück. Für Seiten mit eigenem Layout.

Offen

Ohne Passwort abrufbar. Trägt noindex, ist per Link aber erreichbar. Bewusst so.
